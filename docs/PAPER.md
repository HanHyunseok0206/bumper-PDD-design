## 초록 (Abstract)

*(작성 예정 — 전체 연구가 마무리되면 결과를 요약해 채울 것)*

본 연구는 차량 범퍼의 충돌 에너지 흡수 성능(SEA, Specific Energy Absorption)을 극대화하면서, 재료 물성 편차·제조 공차·충돌 조건 등의 불확실성 아래에서도 그 성능이 안정적으로 유지되는 강건 설계(robust design)를 목표로 한다. 카티아(CATIA)로 범퍼 3D 형상을 파라메트릭하게 모델링하고, 아바쿠스(Abaqus/Explicit)로 충돌 유한요소(FE) 해석을 수행해 SEA를 산출한다. FE 해석은 계산 비용이 크므로, 소수의 실험계획법(DOE) 표본만으로 전체 설계공간의 응답을 근사하는 서로게이트 모델링을 도입한다. 먼저 다항식 차원분해(PDD, Polynomial Dimensional Decomposition)를 이용해 설계변수별 민감도를 분석하고, 실제 예측 서로게이트는 비선형·비매끄러운 충돌 응답에 더 적합한 크리깅(Kriging) 모델로 구축한다. 이렇게 얻은 서로게이트 위에서 평균-표준편차 기반 강건 목적함수를 구성하고 최적화를 수행한다.

## 1. 서론

차량 충돌 시 범퍼는 가장 먼저 에너지를 흡수하는 구조로, 탑승자와 보행자 안전에 직접적인 영향을 준다. 범퍼 설계에서는 흡수 에너지를 질량으로 나눈 비에너지흡수율(SEA)을 높이는 것이 핵심 목표인데, 이는 같은 무게로 더 많은 충돌 에너지를 흡수한다는 의미로 경량화와 안전성을 동시에 만족시키는 지표다. 그러나 실제 양산 환경에서는 재료 물성의 편차, 두께 등 제조 공차, 충돌 속도·각도의 변동성 등 다양한 불확실성이 존재하며, 이러한 불확실성 아래에서도 SEA가 크게 흔들리지 않는 **강건한 설계**가 요구된다.

이 연구는 이러한 문제를 해결하기 위해 서로게이트 모델링 기반 강건 최적 설계 프레임워크를 구축한다. 범퍼 형상은 카티아로 파라메트릭하게 설계하고, 충돌 해석은 아바쿠스로 수행한다. 유한요소 해석은 계산 비용이 크기 때문에, 소수의 DOE 표본으로 얻은 해석 결과로부터 값싼 서로게이트를 만들고, 그 위에서 민감도 분석과 강건 최적화를 수행하는 전략을 취한다. 서로게이트 구축 단계에서는 다항식 차원분해(PDD)를 이용해 어떤 설계변수가 SEA에 실질적인 영향을 주는지 먼저 screening하고, 실제 예측 모델은 비선형적이고 불연속적인 특성을 가질 수 있는 충돌 응답에 더 적합한 크리깅(Kriging) 서로게이트로 구축한다. 이 조합을 통해 PDD 고유의 해석적 분산 분해 능력과, 크리깅의 국소 적응적 예측 능력을 모두 활용하는 것이 본 연구의 방법론적 특징이다.

## 2. 이론적 배경

### 2.1 PDD와 전역 민감도 분석

다항식 차원분해(Polynomial Dimensional Decomposition, PDD)는 다변수 함수를 분산분석(ANOVA) 방식으로 분해해, 상수항·단독 변수 효과·변수 간 교호작용의 합으로 표현하는 기법이다. 각 성분 함수를 직교 다항식(본 연구에서는 균등분포 입력에 적합한 르장드르 다항식)으로 전개하고, 실제 해석 결과에 최소자승 회귀를 적용해 계수를 추정한다. 상호작용을 포함하는 변수 개수(S)와 다항식 차수(m)를 제한해 절단하면, 변수 개수가 많아져도 필요한 항의 개수가 조합적으로 폭발하지 않는다는 장점이 있다. 얻어진 계수로부터 각 변수·변수 조합이 전체 분산에 기여하는 비율(Sobol 민감도 지수)을 계산할 수 있어, 설계변수 스크리닝(변수 축소)에 효과적으로 활용된다.

입력변수 `dim`개(x₁, ..., x_dim)에 대해 차수 `n`, 상호작용 변수 개수 `S`까지 절단한 PDD 근사식은 다음과 같다.

```
f(x) ≈ c₀
      + Σᵢ₌₁^dim Σⱼ₌₁ⁿ cᵢⱼ · Pⱼ(xᵢ)                                     [단독 변수 항]
      + Σ_{k<l} Σᵢ₌₂ⁿ Σⱼ₌₁ⁱ⁻¹ cₖₗ,ⱼ,ᵢ₋ⱼ · Pⱼ(xₖ) · Pᵢ₋ⱼ(xₗ)               [2변수 상호작용 항, S=2일 때만]
```

여기서 `Pⱼ`는 j차 르장드르(Legendre) 다항식으로, 다음 점화식으로 계산한다.

```
P₀(x) = 1,   P₁(x) = x
P_{m+1}(x) = [(2m+1)·x·Pₘ(x) − m·Pₘ₋₁(x)] / (m+1)
```

계수 `c`는 각 항을 평가한 값들로 이루어진 설계행렬 `Φ`(표본 수 × 항 개수)에 대해 최소자승으로 추정한다.

```
C = Φ⁺ Y     (Φ⁺: Φ의 무어-펜로즈 유사역행렬, 수치적으로 pinv(Φ)Y로 계산)
```

변수(조합) `S`의 민감도(Sobol) 지수는, `S`에서만 나온 항들이 만드는 예측값의 경험적 분산을 전체 분산으로 나눈 비율로 정의한다.

```
D_S = Σ_{i: 항 i가 변수집합 S에서만 옴} Var[ Cᵢ · Φᵢ ]
S_S = D_S / Σ_{S'} D_{S'}                (0~1, 전체 합=1)
```

(주: 사용한 르장드르 기저가 표본 분포 하에서 완전한 정규직교가 아니므로, 이상적인 Sobol 분해처럼 계수 제곱합만으로 계산하지 않고 항별 예측값의 경험적 분산으로 근사한다 — `validation_and_benchmarks/PDD_Legendre_ver4.ipynb`의 `get_sobol2`와 동일한 근사.)

차수 `n`과 상호작용 차수 `S`는 홀드아웃 검증 R²를 기준으로 자동 선택한다(학습 데이터만으로 선택하면 차수를 올릴수록 항상 좋아 보여 과적합되므로 검증셋 기준으로 판단).

```
(n*, S*) = argmax_{(n,S)} R²_valid(n, S)
```

### 2.2 크리깅(Gaussian Process) 서로게이트

크리깅은 관측된 표본들 사이의 상관구조(커널 함수)를 이용해 미관측 지점의 응답을 확률적으로 보간하는 비모수적 회귀 기법이다. PDD와 같은 전역 다항식 기반 서로게이트와 달리, 크리깅은 국소적으로 적응하는 예측을 하기 때문에 응답면이 비선형적이거나 매끄럽지 않은(non-smooth) 경우에도 상대적으로 강건한 예측 성능을 보인다. 범퍼와 같은 박판 구조물의 충돌 흡수 거동은 좌굴 모드 전환 등으로 설계변수에 대해 꺾인(kinked) 형태의 응답을 보일 수 있어, 이런 특성을 다루는 데 크리깅이 적합하다고 판단했다(3.5절 참고).

크리깅은 관측값이 평균 0(또는 상수 트렌드)인 가우시안 프로세스(GP)에서 나왔다고 가정한다. 두 입력 `x`, `x'` 사이의 공분산은 커널 함수 `k(x,x')`로 정의하며, 본 연구에서는 Matérn 커널(ν=5/2)에 화이트 노이즈 항을 더해 사용한다.

```
k(x, x') = σ_f² · (1 + √5·r/ℓ + 5r²/(3ℓ²)) · exp(−√5·r/ℓ) + σ_n²·δ(x, x'),   r = ‖x − x'‖
```

`ℓ`(length scale)은 등방성(isotropic) 커널에서는 스칼라 하나지만, 변수별 민감도 차이가 큰 경우(3.5절 참고) 변수마다 다른 `ℓᵢ`를 쓰는 비등방성(ARD, Automatic Relevance Determination) 커널로 확장할 수 있다. 표본 `N`개의 학습 데이터 `(X, y)`가 주어졌을 때, 새 입력 `x*`에서의 예측 평균·분산은 다음과 같다.

```
μ*(x*) = k*ᵀ (K + σ_n² I)⁻¹ y
σ*²(x*) = k(x*, x*) − k*ᵀ (K + σ_n² I)⁻¹ k*
```

여기서 `K`는 학습 데이터 간 공분산 행렬(N×N), `k*`는 `x*`와 학습 데이터 사이의 공분산 벡터(N×1)이다. 하이퍼파라미터(σ_f, ℓ, σ_n)는 로그 한계우도(log marginal likelihood)를 최대화해 추정한다.

```
log p(y | X) = −½ yᵀ(K+σ_n²I)⁻¹y − ½ log|K+σ_n²I| − (N/2) log(2π)
```

### 2.3 강건 설계 최적화(RDO)

강건 설계 최적화는 목적함수의 평균 성능과 그 변동성(표준편차)을 동시에 고려하는 최적화 기법이다. 본 연구에서는 서로게이트로 근사한 SEA에 대해 다음과 같은 목적함수를 사용한다.

```
maximize   J(x) = mean(SEA) − κ · std(SEA)
```

여기서 `x`는 설계변수, `κ`는 강건성에 대한 가중치이다. 설계변수는 카티아에서 직접 조절하는 변수(design variable, 이하 x_d)와, 재료 물성·충돌 조건처럼 불확실성을 갖는 변수(noise variable, 이하 x_n)로 구분한다.

mean(SEA)·std(SEA)는 x_d를 고정한 채 x_n만 그 범위 안에서 `M`개 몬테카를로 표본으로 흔들어, 학습된 서로게이트 `Ĝ`(크리깅 예측 함수)로 재평가해 추정한다. FE를 다시 돌리는 게 아니라 이미 적합된 서로게이트만 재평가하는 것이라 비용이 거의 들지 않는다.

```
mean(SEA; x_d) ≈ (1/M) Σ_{m=1}^{M} Ĝ(x_d, x_n^(m))
std(SEA; x_d)  ≈ √[ (1/(M−1)) Σ_{m=1}^{M} (Ĝ(x_d, x_n^(m)) − mean(SEA; x_d))² ],   x_n^(m) ~ U(노이즈 변수 범위)
```

최적화 문제는 x_d에 대해 J(x_d)를 최대화하는 것으로, 박스 제약(설계변수 범위)과 필요시 질량·PCF 등 추가 제약을 둔다.

```
x_d* = argmax_{x_d}  J(x_d) = mean(SEA; x_d) − κ · std(SEA; x_d)
        subject to   x_d ∈ [설계변수 하한, 상한],  (필요시) 질량 ≤ 상한 등
```

이 문제는 그래디언트 기반의 국소 제약조건부 최적화 기법인 SLSQP(Sequential Least Squares Quadratic Programming)로 푼다(3.6절 참고).

## 3. 연구 방법

### 3.1 범퍼 형상 설계 (CATIA)

*(내용 추가 예정)*

범퍼 빔·크래시박스의 기본 3D 형상은 CATIA로 설계했다(`CAD/` 폴더에 원본 CATPart/CATProduct 보관). 다만 DOE 실행을 위한 설계변수별 형상 재생성은 카티아 왕복 없이 진행하는 쪽으로 방향을 바꿨다(3.2절 참고) — 초기에 검토했던 `catia_automation/generate_doe_geometry.py` 기반 자동화는 현재 파이프라인에서는 쓰지 않는다.

### 3.2 충돌 FE 해석 (Abaqus)

*(내용 추가 예정)*

충돌 해석은 Abaqus/Explicit으로 수행한다. 설계변수는 카티아가 아니라 아바쿠스 안에서 직접 파라미터로 정의하고, 각 파라미터의 min/max 범위를 지정해 그 안에서 DOE 점을 뽑아 형상 생성·메싱(솔리드 요소)·해석까지 자동화돼 있다. 이 방식으로 1~3차 DOE(100/603/4949 trial)를 문제없이 뽑아 SEA·질량·내부에너지 등을 CSV로 추출해왔다. 정확한 파라미터 정의 방식, 아바쿠스 버전, 재질모델·요소 타입 등 세부 사항은 추후 보강한다.

### 3.3 실험계획법(DOE)

DOE는 Latin Hypercube Sampling(`DOE_sampling.ipynb`)으로 설계공간을 샘플링한다. 설계변수 7개(빔 두께·반경·높이, 크래시박스 두께·길이·리브 오프셋·필렛 중심 오프셋)와 불확실성(noise) 변수 2개(항복강도 편차, 두께 공차)를 함께 흔들되, 두 그룹의 변동폭은 근본적으로 다르게 설정했다. 설계변수는 공칭값 대비 ±15%(beam_height만 카티아 형상 업데이트 실패 확인 후 -10%/+15%로 비대칭 조정), noise 변수는 항복강도 ±10%대·두께 공차 ±0.1mm 수준으로 훨씬 좁게 잡았다.

이 구분은 강건 설계 최적화(Robust Parameter Design) 이론에서 "제어(설계)변수는 최적점을 찾기 위해 능동적으로 넓게 탐색해야 하는 변수, 노이즈 변수는 실사용 환경에서 통제 불가능한 작은 규모의 불확실성(제조 공차 등)을 나타내는 변수"로 원천적으로 다르게 다루는 것과 같은 논리다[^1]. 크래시워시니스 박판 구조물의 두께 sizing 최적화 문헌에서도 설계변수 탐색 범위를 제조 공차보다 훨씬 넓게, 공칭값 대비 대략 10~30% 이상으로 잡는 것이 일반적이다[^2].

**실제 DOE 실행 경과**: 이 구분이 실무에서 항상 매끄럽게 전달되지는 않았다는 점 자체가 하나의 방법론적 교훈이라 기록해 둔다.

- **1차 DOE (2026-09-22 수령, 100 trial)**: 팀원이 Abaqus 쪽에서 독자적으로 생성한 데이터로, 변수 19개(B1~B9, C1~C10)가 모두 공칭값 대비 ±1.7~3.3%라는 좁은 범위로 흔들려 있었다. 사후 확인 결과 이 범위는 ISO 공차 기준으로 의도된 것이었으나, 이는 본래 설계변수에 배정했어야 할 넓은 탐색 범위가 아니라 노이즈 변수 수준의 변동폭이었다 — 즉 이 100 trial은 하나의 공칭 형상 주변을 제조공차 수준으로만 흔든 노이즈 스터디에 해당하고, 설계공간 탐색용 DOE로는 쓸 수 없었다(원인 진단은 3.4절 참고).
- **2차 DOE (2026-09-23 수령, 603 trial)**: 위 문제를 확인한 뒤 설계변수 범위를 공칭값 대비 약 13%까지 확대하고, 명시적(explicit) 해석의 time step을 줄여 수치적 노이즈도 함께 낮춘 데이터로 재요청했다. 다만 변수 중 C9·C10 두 개는 나머지(약 13%)와 달리 오히려 1차보다도 좁은 범위(약 1.0~1.2%)로 나타났다.
- **3차 DOE (2026-09-29 수령, 4949 trial)**: 표본 수를 대폭 늘려 받았다. 설계변수 범위는 약 6.6%로 2차보다 오히려 좁아졌으나(원인 확인 중), 표본 수 증가의 효과가 범위 축소를 상쇄하고도 남아 3.4절에 서술하듯 가장 신뢰할 수 있는 민감도 분석 결과를 얻었다. C9·C10은 1~3차 내내 계속 약 1% 수준에 머물러 있어, 우연이 아니라 이 두 변수만 생성 방식이 다른 구조적 원인이 있을 가능성이 있다(확인 중).

3차 데이터로 "범위 확대"와 "표본 수 증가" 중 어느 쪽이 민감도 분석 신뢰도 개선에 더 지배적인 요인인지 서브샘플링 실험으로 분리해 확인했다(`pdd_range_vs_samples_ablation_20260923.py`). 2차(넓은 범위) 데이터에서 표본만 90개로 줄이면 검증 R²가 오히려 음수(-0.160)로 나빠지고, 표본이 250개를 넘어야 개선이 나타나기 시작했다 — 범위 확대는 "설계 신호가 데이터에 존재하는지"를 결정하는 전제조건이지만, 그 신호를 과적합 없이 추출하려면 결국 충분한 표본 수가 필요하다는 것을 시사한다. 3차 DOE의 결과(범위는 2차보다 좁아졌음에도 표본 증가만으로 더 좋은 결과를 얻은 것)는 이 결론과 일치한다.

- **4차 DOE (계획, 2026-09-29 기준)**: 1~3차 DOE는 전부 설계변수만 흔든 데이터라 노이즈 변수가 없어, 3.6절의 강건 목적함수(mean−κ·std)를 계산할 수 없는 상태다. 원래 계획(위 문단)은 노이즈 변수를 항복강도 편차·두께 공차 2개로 잡고 둘 다 형상은 그대로 둔 채 아바쿠스 입력단(재질 카드·쉘 section thickness)에서만 반영하는 것이었는데, 이는 FE 모델이 쉘 요소라는 전제 하에서만 성립한다. 실제로는 카티아 솔리드 형상을 그대로 임포트해 솔리드(continuum) 요소로 메싱하고 있음을 확인해, 두께는 요소에 붙는 별도 속성이 아니라 3D 형상 자체에 내재된 값이다. 따라서 두께 공차를 형상 변경·재메싱 없이 반영할 방법이 없고(반영하면 공차 효과와 메시 차이가 뒤섞임), 이번 라운드에서는 두께 공차 대신 형상과 무관하게 반영 가능한 후보(항복강도 편차, 충돌 초기 속도, 탄성계수, 마찰계수 등 재질 카드·초기/접촉 조건만 바꾸면 되는 변수) 중 하나를 우선 적용해 4차 DOE를 요청했다. 첫 시도가 성공하면 서로 다른 불확실성 범주(재료 물성 vs 충돌 조건)에서 하나를 더 추가해 노이즈 변수 2개 구성을 재구성할 계획이다(3개 이상은 서로게이트 학습에 필요한 표본 차원이 늘어나는 비용 대비 이득이 적다고 판단해 배제).

*(주의: 위 사례는 설계변수와 노이즈 변수의 범위를 구분하는 이론적 근거는 명확해도, 협업 과정에서 "범위를 얼마나 넓게 잡을지"에 대한 정량적 기준을 미리 합의해 두지 않으면 재작업이 발생할 수 있음을 보여준다. 최종 논문에서는 이 경험을 DOE 설계 시 유의점으로 서술할 수 있다.)*

### 3.4 PDD 기반 민감도 분석

PDD 구현체의 정확성은 실제 데이터 적용에 앞서, 이론적으로 민감도 지수가 알려진 Ishigami 벤치마크 함수로 검증했다. 검증셋 기반으로 다항식 차수를 선택하도록 구성해, 학습 데이터만으로 차수를 선택할 때 발생하는 과적합 문제를 방지했다.

**실제 데이터 적용**: 3.3절의 1차·2차·3차 DOE 데이터에 각각 PDD를 적합해 비교했다. 파라미터 수(k) 대비 표본 수(N)의 비율이 결과 신뢰도에 미치는 영향이 뚜렷하게 드러났다.

| | 1차 (N=90) | 2차 (N=603) | 3차 (N=4949) |
|---|---|---|---|
| 선택된 차수 | n=1(선형), 상호작용 없음 | n=3(3차), 상호작용 없음 | n=6(6차), 상호작용 없음 |
| 파라미터 수 k (k/N) | 20 (0.222) | 58 (0.096) | 115 (0.023) |
| 전체 학습 R² | 0.478 | 0.424 | 0.424 |
| 10-seed 검증 R² 평균 (표준편차) | 0.002 (0.296) | 0.274 (0.088) | **0.427 (0.047)** |
| 학습R² − 검증R² 격차 | 0.475 | 0.150 | **-0.003** |

1차는 파라미터 대비 표본이 부족해(k/N=0.222) 학습 R²는 높아 보여도 검증 분할을 바꾸면 R²가 -0.50~+0.36까지 흔들려 신뢰할 수 없었다. 2차는 표본이 늘고 설계변수 범위가 넓어지며 k/N이 0.096으로 낮아져 학습-검증 격차가 크게 줄었다(0.475 → 0.150). 3차는 표본이 다시 8배 가까이 늘며 k/N이 0.023까지 낮아져, 학습R²-검증R² 격차가 사실상 0(-0.003)이고 10개 시드 전부 0.31~0.49 사이로 좁게 모이는, 지금까지 중 가장 신뢰할 수 있는 결과를 얻었다. (n=6은 탐색 상한에 우연히 걸린 값이 아니라, patience 제약을 풀고 n=12까지 확인해도 R²가 0.40~0.41 선에서 정체하는 것을 확인해 실제 최적점임을 검증했다.)

민감도 지수(SEA 분산 기여율) 기준 상위 변수는 표본이 충분한 2차·3차에서 뚜렷하게 수렴했다. **상위 5개 변수 중 4개(B9, B4, C2, C4)가 2차·3차 모두에서 겹쳤고**, 그중 B9·B4는 두 데이터셋 모두 1·2위를 다퉜다(3차 기준 B4 34%, B9 30%). 1차는 검증 R²가 거의 0으로 신뢰도가 낮아 이 비교에서는 참고만 하되 제외했다. 세 데이터셋의 순위 비교는 `pdd_sensitivity_comparison_20260929.png`에 시각화했다. `DESIGN_IDX`/`NOISE_IDX`의 최종 확정은 3.5절의 크리깅 서로게이트 정확도와 교차 확인한 뒤 진행할 예정이나, B9·B4·C2·C4를 핵심 설계변수 후보로 볼 근거는 이제 충분히 탄탄해졌다.

### 3.5 서로게이트 모델 선정: PDD vs 크리깅

범퍼 충돌 응답은 좌굴 모드 전환 등으로 인해 설계변수에 대해 비선형적이고 매끄럽지 않게 변할 수 있어, 전역 다항식 기반의 PDD보다 국소 적응형인 크리깅이 최종 예측 서로게이트로 더 적합할 것으로 판단했다. 이를 실증하기 위해, 두 변수 간 상호작용을 포함하면서 인위적으로 꺾임(kink)을 갖는 합성 벤치마크 함수를 구성하고, 동일한 학습 표본(150개)으로 PDD와 크리깅을 각각 적합한 뒤 독립된 검증 표본(1,000개)으로 예측 정확도를 비교했다.

| 모델 | R² | RMSE |
|---|---|---|
| PDD | 0.930 | 0.208 |
| 크리깅 | 0.965 | 0.147 |

비교 결과 크리깅이 더 높은 정확도를 보였으며, 특히 응답이 급격히 꺾이는 지점 부근에서 PDD는 곡선을 뭉툭하게 뭉개는 반면 크리깅은 실제 꺾임을 더 근접하게 추적했다(`validation_and_benchmarks/PDD_vs_Kriging_benchmark.ipynb`의 시각화 참고). 이 결과를 바탕으로 본 연구에서는 **PDD는 변수 민감도 분석(스크리닝) 용도로, 실제 예측 서로게이트는 크리깅으로** 역할을 분담했다.

*(주의: 이 비교는 합성 벤치마크 기준이며, 변수 간 상호작용이 없거나 크리깅 커널을 부적절하게 고정할 경우 반대의 결과가 나올 수 있음을 확인했다.)*

**실제 데이터 예비 검증**: 2차 DOE 데이터(N=603)에 등방성 Matern 커널(nu=2.5, 전 변수 공통 단일 length_scale) 크리깅을 19개 변수 전체에 대해 학습해 보았다. 5-fold 교차검증 R²는 10-seed 평균 0.170(±0.012)으로, 같은 데이터에서 PDD가 얻은 검증 R²(0.274)보다 오히려 낮았다. 원인으로는 3.4절에서 확인했듯 SEA 분산의 약 절반이 변수 하나(B9)에 집중된 반면, 지금 쓰는 등방성 커널은 모든 변수에 동일한 length_scale을 가정해 이런 편중된 민감도 구조를 표현하지 못하기 때문으로 추정한다. 변수별로 서로 다른 length_scale을 학습하는 비등방성(ARD) 커널로 전환하는 것을 다음 단계로 계획 중이며, 이 절의 결론(크리깅이 PDD보다 우수하다는 3.5절 서두의 합성 벤치마크 결과)이 실데이터에서도 재현되는지는 이 개선 이후 다시 확인해야 한다.

### 3.6 강건 목적함수 및 최적화

목적함수·몬테카를로 추정식·최적화 정식화는 2.3절에 정리했고, 코드 골격은 `Kriging_bumper_SEA.ipynb`에 구현되어 있다. 다만 이를 실행하려면 노이즈 변수(x_n)가 있어야 하는데, 3.3절에서 서술했듯 1~3차 DOE는 설계변수만 흔든 데이터라 아직 실행하지 못했다 — 4차 DOE로 노이즈 변수가 확보되는 대로 진행할 예정이다.

질량(`Total_Mass`)은 1차 DOE부터 매 trial마다 이미 로깅되고 있어, 추후 최적화에 질량 상한 제약을 추가할 때 별도 데이터 요청 없이 기존 데이터를 바로 쓸 수 있다.

서로게이트 입력 차원은 19개 설계변수 전체가 아니라 3.4절의 PDD 스크리닝 결과(B9, B4, C2, C4 등 누적 기여율 85~90% 수준까지)로 추린 변수만 `DESIGN_IDX`로 남기고, 기여도가 낮은 나머지는 공칭값(평균값)으로 고정해 차원을 줄일 계획이다. 이는 3.5절에서 확인한 크리깅의 한계(등방성 커널이 편중된 민감도 구조를 못 살림)를 완화하는 목적도 겸한다.

### 3.7 능동학습 및 베이지안 최적화 도입 (AI 요소)
